## Средняя сложность

### №7. Перегрузка оператора `+`

Модуль `lab3/vector.py`. Класс `Vector` хранит координаты в
неизменяемом кортеже и перегружает `__add__`: оператор складывает
два вектора покоординатно. Если второй операнд не является вектором,
метод возвращает `NotImplemented`, и Python сам поднимает `TypeError`.
Для векторов разной длины выбрасывается `ValueError` с понятным
сообщением. Дополнительно реализованы `__eq__`, `__hash__`, `__len__`
и `__getitem__`, чтобы вектор можно было сравнивать и использовать в
множествах.

### №9. Класс для работы с файлами

Модуль `lab3/filetool.py`. Класс `TextFile` инкапсулирует путь и
кодировку и открывает файл только на время конкретной операции. Есть
методы `write`, `append`, `read`, `lines`, `find` и свойство `exists`.
Кодировка настраивается в конструкторе; поиск возвращает номера строк
с единицы. Ошибка отсутствующего файла не подавляется: `read`
пробрасывает стандартный `FileNotFoundError`.

### №3. Класс «Банковский счёт»

Модуль `lab3/account.py`. Класс `BankAccount` хранит владельца, остаток
`Decimal` и историю операций. `deposit` и `withdraw` проверяют, что
сумма положительна, а снятие не превышает остаток. При недостатке
средств выбрасывается собственное исключение `InsufficientFunds`,
причём баланс и история остаются прежними. Денежные значения
квантуются до двух знаков с округлением `ROUND_HALF_UP`, поэтому
расчёты не накапливают ошибку двоичной плавающей точки.

## Повышенная сложность

### №7. Мини-ORM: класс «Таблица»

Модуль `lab3/table_orm.py`. Класс `Table` объявляет схему: имя,
упорядоченный список колонок и необязательный уникальный ключ. Метод
`insert` проверяет наличие всех колонок, отсутствие лишних и
уникальность ключа, а возвращает копию строки. Метод `select`
поддерживает фильтры по равенству колонок и произвольный предикат.
Хранение в памяти и возврат копий защищают таблицу от случайного
изменения извне.

### №5. Сериализация объектов в JSON

Модуль `lab3/json_encoder.py`. Класс `JsonSerializer` рекурсивно
преобразует dataclass'ы, `datetime`/`date`/`time`, `Decimal`, `Path`,
множества и вложенные контейнеры в JSON-совместимые значения.
Объекты могут реализовать метод `to_json()` и тем самым задать своё
представление. Неподдерживаемый тип приводит к `SerializationError`,
а не к неинформативной ошибке модуля `json`. Кириллица сохраняется
без экранирования.
